# 📋 [Board](https://pi.tail2e200c.ts.net)

Vestaboard controller.

## 🛠️ Setup

Configure `.env`:

```sh
VESTABOARD_HOST=...     # Vestaboard local hostname (unset for dry-run mode)
VESTABOARD_KEY=...      # Vestaboard local API key
```

## 🚀 Deploy

Build and install on Raspberri Pi:

```sh
deploy/deploy.sh
```
