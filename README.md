# 📋 Board

Home Vestaboard controller.

## 📖 Usage

```sh
cargo run --release -- show "Hello World"   # Show text and exit
```

## 🛠️ Setup

Add keys to `.env`:

```sh
VESTABOARD_HOST=...     # Vestaboard local hostname
VESTABOARD_KEY=...      # Vestaboard local API key
VESTABOARD_TEST=...     # 1 to enable dry-run mode
```
